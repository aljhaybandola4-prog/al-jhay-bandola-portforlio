# Al Jhay A. Bandola — Portfolio Website

A responsive cyberpunk/synthwave portfolio built with HTML, CSS, and JavaScript.

## Run the website
1. Extract this ZIP.
2. Open the extracted `project` folder in VS Code.
3. Open `index.html` and click **Go Live** if you have the Live Server extension, or open `index.html` in your browser.

## Update the profile picture
The profile photo is still a placeholder. Add your image to this folder, then replace the profile placeholder in `index.html` with an `<img>` element and style it in `style.css`.

Project **VIEW** links open the corresponding GitHub or Figma page in a new tab.
